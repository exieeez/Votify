# Votify Mobile — дизайн (экспорт из Google Stitch)

Источник: проект Stitch «Votify Android Music Player». Файлы `*.html` — сгенерированная
Tailwind‑разметка экранов (справочник по отступам, размерам, цветам), `*.png` — рендеры.

## Дизайн‑система

**Основная: `DESIGN-monochrome.md`** — строгий ахроматический дарк‑мод (чёрный / графит / белый),
Inter, Material 3‑геометрия. Именно в ней сделаны экраны `home`, `library`, `settings`
и логотип.

`DESIGN-tonal-alt.md` — альтернативная фиолетовая палитра Material You (`#e9ddff` primary).
Экраны `search` и `player` были сгенерированы на её конфиге, но фактически используют
серые hex‑цвета — при реализации приводим их к монохрому.

### Ключевые токены (monochrome)

| Токен                       | Значение  | Где                                              |
| --------------------------- | --------- | ------------------------------------------------ |
| `pitch-black`               | `#000000` | фон под обложками, инвертированный текст         |
| `surface-base`              | `#121212` | корневой фон экрана                              |
| `surface-container`         | `#1E1E1E` | карточки, списки, мини‑плеер, поля ввода         |
| `surface-container-high`    | `#2A2A2A` | чипы, hover, активная строка поиска              |
| `surface-container-highest` | `#383838` | неактивные pill‑чипы, границы                    |
| `border-subtle`             | `#2A2A2A` | 1px границы карточек, разделители                |
| `border-prominent`          | `#48484A` | активные поля, границы чипов                     |
| `text-primary`              | `#FFFFFF` | заголовки, названия треков, активные иконки      |
| `text-secondary`            | `#E5E5EA` | body, названия строк списка                      |
| `text-muted`                | `#8E8E93` | подписи, исполнители, длительности, placeholder  |
| `primary`                   | `#FFFFFF` | заливка Play/Pause, активный чип, ползунок       |
| `on-primary`                | `#000000` | иконка/текст на белом                            |

- Шрифт: **Inter** 400/500/600/700, кириллица. Табличные цифры для таймкодов.
- Иконки: **Material Symbols Outlined**.
- Радиусы: pill `9999px` (чипы, кнопки, поиск), `1.5rem` (мини‑плеер, группы), `1rem` (карточки, обложки), `0.5rem` (миниатюры в списке).
- Сетка: 8pt, поля экрана 16px, gutter 12px.
- Без теней — глубина только тональными ступенями + 1px границы.
- Мини‑плеер: 64px, отступ 8px по бокам, `#1E1E1E` 90% + blur, 2px прогресс снизу.
- Нижняя навигация: 72px, 3 вкладки — **Главная / Поиск / Коллекция** (+ Настройки на некоторых макетах).

## Соответствие бекенду

| UI                                  | Эндпоинт                                        |
| ----------------------------------- | ----------------------------------------------- |
| Моя волна / Инди‑волна              | `GET /api/custom-wave?seeds=…&trackSeeds=…`     |
| Рекомендовано / Микс дня / Топ 100  | `GET /api/recommendations`                      |
| Поиск                               | `GET /api/search?q=…`                           |
| Артист                              | `GET /api/artist?name=…`                        |
| Воспроизведение                     | `GET /api/stream?id=…` (Range)                  |
| Текст песни                         | `GET /api/lyrics?track=…&artist=…`              |
| Импорт из сервиса                   | `GET /api/playlist?url=…`, `/api/soundcloud/import` |
| Качество стриминга                  | `POST /api/network/settings { audioQuality }`   |
| Профиль                             | `/api/auth/*` (локально) или Firebase Auth      |

Нет на бекенде (нужно добавить или делать на клиенте): история прослушиваний, «Любимые»,
плейлисты пользователя, кэш/офлайн, очередь, подкасты, эквалайзер, кроссфейд.
