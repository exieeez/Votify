# Votify на iPhone без своего сервера

Инструкция для случая «хочу приложение на iPhone, компьютера/сервера под рукой нет».
Итог: адрес вида `https://votify-xxxx.onrender.com`, добавленный в Safari на экран
«Домой» — своя иконка, запуск во весь экран, работает из любой сети.

> Если у вас **Android** — сервер не нужен вообще: готовый APK уже самостоятельный
> ([ссылка на APK](https://github.com/exieeez/Votify/releases/download/android-debug/Votify-debug.apk)),
> музыка считается прямо на телефоне.

---

## Шаг 1. Аккаунт Render

1. Откройте https://render.com → **Get Started** → войдите через **GitHub**
   (кнопка «GitHub», аккаунт `exieeez` — если репозиторий приватный, Render попросит
   разрешение на доступ к нему).
2. Карта не нужна: бесплатного плана достаточно.

## Шаг 2. Деплой из репозитория (Blueprint)

1. В панели Render: **New → Blueprint**.
2. Выберите репозиторий **Votify** → **Connect**.
3. Render прочитает `render.yaml` и покажет сервис `votify`. В поле
   **VOTIFY_BASIC_AUTH** впишите логин и пароль через двоеточие, например:

   ```
   votify:придумайте-длинный-пароль
   ```

   Это пароль на весь сервер — без него ваш адрес смогут использовать посторонние.
   В поле **VOTIFY_FIREBASE_CONFIG** можно ничего не писать (см. шаг 5).
4. **Apply** / **Create Resources** → Render начнёт сборку (первая сборка ~5–8 минут:
   ставит Node, скачивает свежий yt-dlp, собирает образ).

## Шаг 3. Проверка

Дождитесь статуса **Live** и откройте выданный адрес (например
`https://votify-abcd.onrender.com`) в браузере на компьютере. Браузер спросит
**логин и пароль** — те, что задали на шаге 2. Появится интерфейс Votify.

## Шаг 4. Ярлык на iPhone

1. На iPhone откройте **Safari** (именно Safari — Chrome так не умеет) и зайдите на
   ваш адрес. Введите логин и пароль.
2. Нажмите **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **Добавить**.
3. На рабочем столе появится иконка Votify. Запуск — во весь экран, без адресной строки.

На Android то же самое в Chrome: **«⋮» → «Установить приложение»**.

## Шаг 5. Чтобы ничего не терялось (по желанию, но советую)

Бесплатный план Render **без диска**: файлы внутри контейнера исчезают при каждом
передеплое. Аккаунты и синхронизацию лучше держать в Firebase:

1. https://console.firebase.google.com → ваш проект `votify-f461a` → **Настройки проекта →
   Ваши приложения → Web** → скопируйте объект `firebaseConfig` (JSON).
2. Render → ваш сервис `votify` → **Environment** → **VOTIFY_FIREBASE_CONFIG** →
   вставьте этот JSON одной строкой → **Save** (сервис перезапустится).
3. После этого регистрация, вход в аккаунт, друзья и Мастерская тем работают через
   Firebase, а не через файлы на сервере — передеплой им не страшен.

## Чтобы сервис не засыпал (по желанию)

Бесплатный сервис засыпает после ~15 минут простоя, и первый запрос после паузы идёт
до минуты. Лечится бесплатным пингом:

1. Заведите https://uptimerobot.com (или аналог) → **Add New Monitor**.
2. Тип **HTTP(s)**, адрес — `https://ваш-адрес/api/health`, интервал **10 минут**.
3. Render разрешает 750 часов инстанса в месяц, круглосуточная работа одного сервиса —
   примерно 730 часов, так что в бесплатный лимит это укладывается.

## Как обновлять

- **Автоматически:** любой push в ветку, из которой развёрнут сервис (`main`), запускает
  новый деплой (`autoDeploy: true`).
- **Вручную:** Render → ваш сервис → **Manual Deploy → Deploy latest commit**.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Сборка упала на шаге `curl yt-dlp` | GitHub временно недоступен — нажмите **Manual Deploy** ещё раз |
| Страница открывается, но музыка не играет | Устаревший yt-dlp (YouTube часто меняет схему) — **Manual Deploy**: образ скачивает свежий бинарник |
| Первый заход после паузы долгий | Это засыпание бесплатного плана — см. раздел про UptimeRobot |
| Забыли пароль от сервера | Render → Environment → измените `VOTIFY_BASIC_AUTH` → Save |
| Хочу без пароля (только дома в Wi-Fi) | Не задавайте `VOTIFY_BASIC_AUTH`. Для адреса в интернете так делать нельзя |

## Вместо Render: другие бесплатные варианты

Votify — обычный Docker-образ, поэтому подойдёт любой хостинг с Docker:

- **Koyeb** — бесплатный веб-сервис, `docker image: ghcr.io/exieeez/votify:latest`,
  переменные те же (`VOTIFY_PORT`, `VOTIFY_BASIC_AUTH`), порт 17217.
- **Fly.io** — `fly launch` из репозитория (нужна карта для верификации), щедрые лимиты.
- **Google Cloud Run** — бесплатный лимит, образ из GHCR, порт 17217, scale-to-zero.
- **Свой ПК** (Windows/Linux/macOS) — если он всё-таки бывает включён: Настройки →
  Основные → «Votify на телефоне» покажет адрес в Wi-Fi сети.

Во всех вариантах логика одна: развернуть образ → задать `VOTIFY_BASIC_AUTH` → открыть
адрес на телефоне → «На экран „Домой“».
