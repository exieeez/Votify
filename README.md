# 🎵 Votify v0.6.0

> Современный, быстрый и стильный десктопный плеер с дизайном Liquid Glass (iOS style), поддержкой оффлайн-музыки, синхронизированных текстов песен и темной темой.

---

## 🌟 Основные особенности v0.6.0

- 📄 **Постраничная навигация в поиске** — результаты поиска разбиты на страницы по 12 треков с удобной панелью переключения страниц (1, 2, 3...).
- ➕ **Сохранение всех треков исполнителя** — кнопка «Сохранить все в плейлист» на странице артиста для добавления всей дискографии.
- 🎵 **Загрузка собственных MP3 треков** — поддержка добавления локальных `.mp3` файлов в настройках с сохранением в оффлайн-базу (IndexedDB).
- 🎛️ **Интерактивные кнопки Play** — стильные круглые кнопки воспроизведения: белые по умолчанию с динамической подсветкой акцентным цветом темы при наведении.
- 🎚️ **Исправление ползунков в настройках** — цветная линия заполнения дорожки аккуратно отображается за каждым регулятором.
- 💿 **Альбомы в поиске** — автоматическое формирование и отображение карточек альбомов в результатах поиска с быстрым переходом.
- 🧪 **Liquid Glass (iOS Style)** — полупрозрачный матовый интерфейс в стиле стекломорфизма (backdrop-filter blur).
- 🗂️ **Двухпанельная медиатека (Master-Detail)** — удобная навигация по плейлистам, оффлайн-трекам и избранному.
- 🎤 **Синхронизированные тексты песен (LRC)** — караоке-режим со встроенным текстом песен и полноэкранным плеером.
- 🎨 **Полная кастомизация оформления** — акцентные цвета, темы («Тёмная», «Полночь», «Контраст»), гарнитура шрифтов.

## 📦 Сборка и запуск

### Требования
- Node.js (v18+)
- npm

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm start
```

### Сборка релизных дистрибутивов (Linux AppImage & deb)

```bash
# Сборка AppImage & deb (Linux)
npx electron-builder --linux AppImage deb

# Сборка .exe (Windows)
npm run build:win
```

Собраные файлы будут находиться в папке `dist/`.
